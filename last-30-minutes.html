0至12分钟 MIPS必须抓住的规则

寄存器与指令方向

32 个通用 registers，每个 32 bits；1 word=4 bytes。 $zero 恒为 0。题目指定哪个寄存器代表哪个变量，就按题目映射。

add  $t0, $s0, $s1    # $t0 = $s0 + $s1
sub  $t0, $s0, $s1    # $t0 = $s0 - $s1
addi $t0, $s0, -7     # $t0 = $s0 - 7；没有真实 subi
sll  $t0, $s0, 2      # 左移2位；低位补0
srl  $t0, $s0, 2      # 逻辑右移；高位补0

先读源旧值，再写目的。 add $t0,$t0,$s1 合法；add ... ,1 不能把 1 当立即数，应该用 addi。srl 对负补码不能当普通除法。

容易混淆 必须记住
add/sub/addi 与 addu/subu/addiu 前者 signed overflow 异常；后者忽略该异常，保留低32位
addi/addiu 的 immediate 都是16位符号扩展，不因 u 改为零扩展
andi/ori 的 immediate 16位零扩展
andi mask 1 保留、0 清零；ori 的1强制置1
nor t,s,zero 对 s 的32位逐位取反
la、li、move、blt 通常为 pseudo-instructions，由 assembler 展开
.data、.text、.word、.asciiz directives，布局指示，不是CPU执行的指令

数组先算地址 再读取内容

int 数组：address(A[i]) = base + 4i
byte 或 char 数组：address(C[i]) = base + i

Base address（基址）是地址，offset（偏移量）以 bytes 为单位。 lw 不自动把 offset 乘 4。word 访问通常要求地址是 4 的倍数。

la $s0, A          # $s0 = A的地址，不是A[0]
lw $t0, 8($s0)     # $t0 = A[2]
sw $t0, 12($s0)    # A[3] = $t0；第一项是数据源

最常用模板：A[i+1]=A[i]+h，base/i/h 在 $s0/$s1/$s2：

sll $t0, $s1, 2
add $t0, $s0, $t0    # $t0 = address of A[i]
lw  $t1, 0($t0)
add $t1, $t1, $s2
sw  $t1, 4($t0)      # A[i+1] 多4 bytes

旧题锚点：2013 Q1(2) 中 [0,1,2,3,4,5]，先取 base+16 的 word，再写到该地址−4：读取 A[4]=4，写 A[3]，结果 [0,1,2,4,4,5]。抓住“地址→下标→值→写入位置”四步。

条件和循环用反条件退出

slt $t0, $s0, $s1   # $t0 = (a<b) ? 1 : 0；本身不跳转
bne $t0, $zero, L   # a<b 时去L
beq $t0, $zero, L   # a>=b 时去L

a>b：交换比较两项，判断 b<a。a≤b：判断 b<a 是否为假。 beq 比相等，bne 比不等；bgtz/blez/bgez/bltz 是与零比较。

# if(a<b) y=a; else y=b;
    slt $t0, $s0, $s1
    beq $t0, $zero, Else
    add $s2, $s0, $zero
    j Done                  # then完成后跳过else
Else:
    add $s2, $s1, $zero
Done:

循环检查清单：初始化 → 条件失败去 Exit → body → 更新 → 回 Loop。

# base=$s0, n=$s1, i=$s2, sum=$s3
    addi $s2, $zero, 0
    addi $s3, $zero, 0
Loop:
    slt  $t0, $s2, $s1
    beq  $t0, $zero, Exit
    sll  $t1, $s2, 2
    add  $t1, $s0, $t1
    lw   $t2, 0($t1)
    add  $s3, $s3, $t2
    addi $s2, $s2, 1
    j Loop
Exit:

执行 n 轮 body，一般检查条件 n+1 次。Immediately after lw 只意味着刚读入，后面的加法／计数可能还没执行。内存被 sw 改写后，下一轮要读新值。以上按课程示例，不启用 delayed branching。

Basic block（基本块）：中间没有跳转，也没有其他分支入口；入口、跳转目标、跳转后下一条可成为块的开头。

字节序和syscall

Word 0x80F17E23 从地址 B 开始：

地址 Little-endian 小端 Big-endian 大端
B 23 80
B+1 7E F1
B+2 F1 7E
B+3 80 23

小端机器从 B+2 读 F1：lb → 0xFFFFFFF1（−15）；lbu → 0x000000F1（241）。sb 只写寄存器最低8位。端序改变字节排列，不反转字节内部的 bits。

ASCII：空格=0x20，'0'=0x30，'9'=0x39；终止符 \0=0。.asciiz 自动多占一个终止字节；字符串指针每轮 +1，word 数组每轮 +4。

MARS syscall：$v0 服务号：1 打印整数（值放 $a0），4 打印字符串（地址放 $a0），5 读整数（结果回 $v0），10 退出。读完后先转存结果，再覆盖服务号：

add  $a0, $v0, $zero
addi $v0, $zero, 1
syscall

机器码先写字段角色

R: op(6) | rs(5) | rt(5) | rd(5) | shamt(5) | funct(6)
I: op(6) | rs(5) | rt(5) | immediate(16)
J: op(6) | target(26)

汇编 add rd,rs,rt，R编码却是 rs、rt、rd。 I型没有 rd；lw/addi 的目的在 rt；sw 的数据源也在 rt，rs 仍是基址。

记什么 数值／规则
寄存器编号 zero=0；v0=2；a0=4；t0..t7=8..15；s0..s7=16..23；t8/t9=24/25
R型常用funct add=32，sub=34，and=36，or=37，nor=39；op=0
sll/srl R型；rs=0，rt为被移位数，rd为结果；funct=0/2
jr R型，rs存完整目标地址，funct=8
I型op addi=8；andi=12；ori=13；lw=35；sw=43；beq=4；bne=5
j op=2；不要因为jr里有jump就把jr当J型

核对例：add $t0,$s1,$s2：

op rs rt rd shamt funct = 0,17,18,8,0,32
000000 10001 10010 01000 00000 100000
hex = 0x02324020

负 immediate 先按 16位补码编码，再填字段。绿卡能查 opcode；优先保证格式、角色、位数写对。

补充速记 Branch和jump地址编码 
branch imm = (target − (PC+4))/4
branch target = PC+4 + sign_extend(imm16)×4

PC 是分支本身地址；基准是 PC+4；字段存 word 位移。例 PC=0x00400020，target=0x00400010：imm=−20/4=−5，16位=0xFFFB。

j target26 = (target_address >> 2) & 0x03FFFFFF
实际目标 = {(PC+4)高4位, target26, 00}

先右移2位再取26位。 jr 则直接使用寄存器里的完整地址。提取 bits i..j（含端点）到低位：先 sll 31−j，再 srl 31−j+i；保留位数 j−i+1。

12至19分钟 逻辑电路抓住方法

Boolean和SOP POS

+ 是 OR，连写是 AND，' 是 NOT。1+1=1。

法则 公式
Complement 互补 A+A'=1；AA'=0
Absorption 吸收 A+AB=A；A(A+B)=A
Distributive 分配 A(B+C)=AB+AC；A+BC=(A+B)(A+C)
De Morgan 德摩根 (AB)'=A'+B'；(A+B)'=A'B'

minterm 在指定行=1；maxterm 在指定行=0。 ABC=101：m5=AB'C，M5=A'+B+C'。SOP 把输出为1的 minterms 相加；POS 把输出为0的 maxterms 相乘。

2012 Q3 的正确化简结果是 AB'+C，B 的反号不能丢。 检验反例：A=1,B=0,C=0 时，AB'+C=1，而 AB+C=0。

NAND-only 的模板：XY+Z=((XY)'Z')'。先生成乘积的反相，再末级 NAND 合并；输入反相可用 NAND(A,A)。题目说“加 NOT 门”与“只能 NAND”时，门数不同。

PLA：AND plane 生成乘积项；OR plane 决定每个输出接哪些项。多个输出可共享乘积项。

K map和MUX

K-map 行列 Gray 顺序：00,01,11,10。 SOP 圈1、POS圈0；每圈为1/2/4/8…格矩形；边缘可环绕、角可相邻、对角线不相邻；可以重叠；保留圈内不变变量，消掉变化变量。

MUX 选择数据；decoder 将编号变成 one-hot 输出。 2^n 路至少需 n 个选择位；数据宽度与选择宽度不同。

题型 立刻写出的结论
4-to-1 MUX由2-to-1组成 3个器件、最少2个独立选择位
8-to-1 MUX由2-to-1组成 7个器件、3个选择位
32-bit 4-to-1 MUX 输出32 bits，选择2 bits
32寄存器选写 5-to-32 decoder
编码N个状态 至少 ceil(log2 N) 个1-bit FF

原题若把每个小MUX的控制信号独立列出，按给定控制信号数量列完整真值表；不要把“最少共享控制位”直接当作原图的输入个数。

Latch和flip flop

元件 必会规则
NOR SR latch S,R=00保持；10置1；01清0；11禁止
NAND低有效SR latch S',R'=11保持；01置1；10清0；00禁止
高有效D latch WE=1时透明，Q跟随D；WE=0保持
D flip-flop 只在指定上升沿或下降沿采样D，其余保持

多个FF同时更新，全部使用边沿前的旧状态。 先写 Q_next=逻辑函数(Q_old,input)，再一起更新，不能边改边算。Asserted=有效；低有效信号 asserted 时是0。

19至25分钟 数字表示抓住分类

补码范围和扩展

n-bit unsigned：0 至 2n−1
n-bit two's complement：−2n−1 至 2n−1−1

负数编码：2^n−|x|，或固定n位取反加1。读负补码：先得 unsigned U，再算 U−2^n。符号扩展复制最高位；零扩展高位补0。

Signed overflow：同号相加得到异号；或直接检查数学结果是否越界。 carry-out 与 signed overflow 不等价。8-bit signed 范围 −128..127；+128不能表示，不能给截断答案。

IEEE先分类E

Single：1/8/23，bias=127；Double：1/11/52，bias=1023。

E字段 F字段 数值／类别
非全0且非全1 任意 normal：(−1)^S×1.F×2^(E−B)
全0 非0 subnormal：(−1)^S×0.F×2^(1−B)
全0 全0 +0或−0
全1 全0 +∞或−∞
全1 非0 NaN

E不是补码；subnormal没有隐含1，指数用1−B。 1.F 指二进制数，例如1.101₂=1+1/2+1/8，不是十进制1.101。

编码顺序：十进制→二进制→1.xxx×2^e→S→E=e+B→去掉隐含1保存F→补足位数。负浮点只改S，不对整个32位取补码。

精确性 Exactness：二进制是否终止、有效位是否放得下、指数是否在范围内，三个都检查。分数约分后的分母含5等非2因子时，二进制不终止。Toward zero（向零舍入）截断有效位不进位；对负数，结果应更接近0。

自定义浮点先拆开指数

总位数N，1位符号、k位指数、f=N−1−k位小数：

B = 2k−1−1
Emax = 2k−2
emax = Emax−B
xmax finite = (2−2−f) × 2emax
xmin normal = 21−B
xmin positive = 21−B−f

最小严格正数包含subnormal时，用最后一条，不是最小normal。 正常区间 [2^e,2^(e+1)) 的间距是 2^(e−f)。

HW2 的1/4/11格式：B=7，最大有限255.9375，最小正数2^(−17)，最大精确正整数255。最大有限值不一定是整数；最大精确整数也不等于“之前每个整数都能表示”。

25至28分钟 七个快速自测

先看题，每题思考约20秒，再展开核对；错题只回看相应规则。

  1. base=$s0，lw $t0,20($s0) 读取int数组第几项？
  2. slt $t0,$s0,$s1 后，什么分支表示 a≥b 时去L？
  3. 0 00000000 10000000000000000000000 的single精确值？
  4. 8-bit 11110110 的signed值和符号扩展16位结果？
  5. 简化 A'B+AB+AC。
  6. 上升沿FF旧Q1Q0=10，D0=Q1，D1=Q0 XOR Q1，下一状态？
  7. sw $t1,−8($s2) 的rs、rt、16-bit immediate分别是什么？
展开七题答案
  1. A[5]，20/4=5。
  2. beq $t0,$zero,L，因为a<b为假。
  3. 2^(−127)，0.1₂×2^(−126)。
  4. unsigned246，signed246−256=−10；扩展为 11111111 11110110。
  5. B(A'+A)+AC 化简为 B+AC。
  6. 11，两个D都使用旧Q1=1,Q0=0。
  7. rs=18，rt=9，imm=0xFFF8；rs为基址，rt为待存的数据。

28至30分钟 最后一屏

看见题目先圈三件事：类型、位宽、要求的时刻。 读清 signed/unsigned、exact、real instructions、preserve、immediately after。

英文指令词 答题动作
circle all correct 多选；别按单选做
show working / justify 写关键算式或理由，不只写答案
exact value 精确分数、2的幂之和或精确十进制
strictly positive 排除0
inclusive 位提取包含两端；位数j−i+1
preserve 不覆盖指定寄存器的旧值
real / pure MIPS 避免la/li/move/blt等伪指令
immediately after 只执行到指定指令刚结束

概念题一眼分清：CPU=datapath+control；五部件还包括input/output/memory。ISA是软硬件接口，允许不同内部实现。n位byte地址空间最多2^n bytes；容量换word要再除4。clock period=1/frequency；2GHz对应0.5ns。

过程分模板：补码写范围→变换；浮点写S/E/F类别→有效数→实际指数→数值；电路写表达式→所用法则→化简；MIPS写寄存器映射→有效地址→值→更新；编码写格式→字段→二进制→hex。

交卷前检查：位数是否足够；反号是否丢了；word offset是否乘4；负immediate是否16位补码；sw是否写对位置；if是否漏j；循环是否更新；FF是否用旧值；subnormal是否误用1.F。
